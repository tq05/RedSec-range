# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1. In short: be respectful, welcoming, and constructive. Harassment and
discrimination are not tolerated.

Because this is security tooling, one project-specific norm applies: keep
contributions and discussion oriented toward **education and defense**. Do not use
the issue tracker, PRs, or community spaces to coordinate attacks on real systems or
to share content whose only purpose is harm outside the isolated lab.

Report unacceptable behavior to the maintainers (set a contact address for your
fork). Maintainers may remove content and contributors that violate this code.
